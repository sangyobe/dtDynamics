## Why rc3

- `v0.1.0-rc3` 유지 사항: rc2의 수정된 direct `${ARTF_INSTALL_DIR}` installation contract
- rc3 추가 사항: publishable package manual, generated Doxygen/Graphviz documentation, 확장된 benchmark/resource inspection, 명확해진 realtime-allocation scope

- Publication-specific manuscript, review, 대형 evidence material 관리 위치: 별도 유지
- 이 release 초점: package source, API documentation, validation, 재사용 가능한 benchmark tooling

## Scope

- 이 candidate 포함 항목:
  - Public namespace와 CMake target: `dt::Dynamics`
  - Production dependency boundary: `dtMath`만
  - model/spec/data layer, computation, integration, realtime use, validation, limitations, example, benchmark, release workflow를 다루는 Doxygen manual page
  - dimension, indexing, frame, stacked-root semantics를 포함한 MuJoCo-style public `dtDynModel`/`dtDynData` field comment
  - Graphviz diagram과 responsive benchmark figure
  - Native, stage, MuJoCo, Pinocchio validation/benchmark path
  - `CompileSpec(spec)`와 fresh `dtDynData::Resize(model)`의 setup/off-loop resource inspection row
  - regression checking용 raw CSV allocation counter 유지 (human-facing timing table에서는 all-zero column 생략)
  - clean source archive를 위한 local development-tool·Python-cache ignore rule

## Installation

```bash
cmake --preset release
cmake --build --preset release -- -j2
cmake --install build/release --prefix "${ARTF_INSTALL_DIR:-$HOME/.local/ART_Framework}"
```

- Consumer 권장 방식: `find_package(dtDynamics CONFIG REQUIRED)` 사용, `dt::Dynamics` link

## Known Limits

- Setup/resource timing 성격: inspection evidence (controller-loop timing 아님)
- C++ allocation counter 성격: diagnostics (complete malloc-family 또는 OS heap trace 아님)
- p99 값 특성: scheduling/frequency-sensitive (현재 report는 fixed CPU affinity와 seven-batch summary 사용, frequency locking·realtime priority는 미적용)
- Validation-only Pinocchio/Boost warning 출처: private dependency prefix (production dependency 아님)
- Publication-specific manuscript material 관리: 별도 유지 (이 candidate에 미포함)
