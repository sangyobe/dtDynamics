## Scope

This release candidate freezes the standalone native `dtDynamics` package:

- Public namespace: `dt::Dynamics`
- Public CMake target: `dt::Dynamics`
- Production dependency boundary: `dtMath` only
- Validation-only references: MuJoCo 3.8.0 and Pinocchio 3.9.0 in the private
  package `.validation_deps/` cache
- Package layers: `dtDynSpec`, `dtDynModel`, and `dtDynData`
- Main runtime entry points: `ComputeDynamicsRNEA`, `ComputeDynamicsCCRBA`,
  `ForwardKinematics`, `ComputeJacobians`, and the point/body/site Jacobian
  term helpers

The native implementation supports the current MuJoCo-compatible tree model
scope used by LeoQuad WBC: world body, fixed bodies, fixed-base and floating-base
fixtures, multi-root fixed and floating fixtures, body/site transforms,
mass/bias-force ingredients, Jacobians, `Jdot`, `Jdot*qvel`, CoM quantities,
centroidal matrix terms, and selected derivative-style terms.

## Known Warnings

The MuJoCo and Pinocchio validation build may print CMake warnings from the
private Pinocchio/Boost validation prefix and `libgomp` runtime path discovery.
They are validation-prefix warnings, not production package dependencies.
The reference executables built and passed in the release audit.

LeoQuad configure may print existing CMake deprecation warnings from shared ART
Framework CMake files. They did not block the installed-package build or
headless trot gate.

## Deferred Scope

The following items remain outside this release candidate:

- equality constraints and closed-chain/four-bar support
- contact simulation, actuator simulation, and torque-controller output
- additional coordinate conventions beyond the single MuJoCo-compatible
  `qpos/qvel` convention documented in the manual
- second-order rigid-body dynamics derivatives beyond the currently implemented
  derivative-style WBC quantities
- removing the remaining LeoQuad controller-facing fixed-size export fields
  used by existing WBC APIs

These are future design tasks, not blockers for the current standalone
dtDynamics package boundary or LeoQuad WBC migration.
