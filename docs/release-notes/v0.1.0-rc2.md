# dtDynamics v0.1.0-rc2 Release Candidate

Author: Joonhee Jo

Date: 2026-07-16

## Identity

- Package version: `0.1.0`
- Tag: `v0.1.0-rc2`
- Commit: tagged commit

## Why rc2

`v0.1.0-rc1` is preserved as historical context, but its LeoQuad handoff
documentation and validation path used the old isolated install prefix
`${ARTF_INSTALL_DIR}/dtDynamics`. The corrected release candidate installs and
validates dtDynamics directly under `${ARTF_INSTALL_DIR}` so downstream ART
packages consume:

- headers from `${ARTF_INSTALL_DIR}/include/dtDynamics`
- the library from `${ARTF_INSTALL_DIR}/lib/libdtDynamics.a`
- CMake package exports from `${ARTF_INSTALL_DIR}/lib/cmake/dtDynamics`

The stale isolated prefix `${ARTF_INSTALL_DIR}/dtDynamics` must not be required
for production or LeoQuad validation.

## Scope

This release candidate freezes the standalone native `dtDynamics` package:

- Public namespace: `dt::Dynamics`
- Public CMake target: `dt::Dynamics`
- Production dependency boundary: `dtMath` only
- Validation-only references: MuJoCo 3.8.0 and Pinocchio 3.9.0 in the private
  package `.validation_deps/` cache
- Package layers: `dtDynSpec`, `dtDynModel`, and `dtDynData`
- Main runtime entry points: `ComputeDynamicsRNEA`, `ComputeDynamicsCCRBA`,
  `ForwardKinematics`, `ComputeJacobians`, and the point/body/site Jacobian
  term helpers

The native implementation supports the current MuJoCo-compatible tree model
scope used by LeoQuad WBC: world body, fixed bodies, fixed-base and floating-base
fixtures, multi-root fixed and floating fixtures, body/site transforms,
mass/bias-force ingredients, Jacobians, `Jdot`, `Jdot*qvel`, CoM quantities,
centroidal matrix terms, and selected derivative-style terms.

## Correct Install Path

Production install uses the ART Framework prefix directly:

```bash
cmake --preset release
cmake --build --preset release -- -j2
cmake --install build/release --prefix "${ARTF_INSTALL_DIR:-$HOME/.local/ART_Framework}"
```

Downstream consumers should resolve the package with:

```cmake
find_package(dtDynamics CONFIG REQUIRED)
target_link_libraries(my_controller PRIVATE dt::Dynamics)
```

LeoQuad defaults `DTDYNAMICS_INSTALL_PREFIX` to `${ARTF_INSTALL_DIR}` for this
release candidate.

## Validation Gate

Before tagging rc2, run:

```bash
tools/audit_release_readiness.sh
```

For the LeoQuad installed-package handoff, run from the LeoQuad repository:

```bash
SIMROBOT_PROFILE_DYNAMICS=1 tools/validate_external_dtdynamics_package.sh
```

The LeoQuad gate must report `direct_artf_prefix=OK`,
`stale_isolated_prefix_pos=-1`, and a passing no-GLFW headless trot sequence.

## Known Warnings

The Pinocchio/Boost CMP0167 warnings and the validation-only `libgomp.so.1`
runtime search-path warning are expected from the private validation dependency
stack and are not production package dependencies.
