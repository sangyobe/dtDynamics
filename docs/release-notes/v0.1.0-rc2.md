# dtDynamics v0.1.0-rc2 Release Candidate

Author: Joonhee Jo

Date: 2026-07-16

## Identity

- Package version: `0.1.0`
- Tag: `v0.1.0-rc2`
- Commit: tagged commit

## Why rc2

- `v0.1.0-rc1` 보존 사유: historical context
- rc1의 한계: LeoQuad handoff documentation과 validation path가 이전 isolated install prefix `${ARTF_INSTALL_DIR}/dtDynamics` 사용
- 수정된 release candidate 방식: `${ARTF_INSTALL_DIR}` 바로 아래에 dtDynamics를 install·validate하여 downstream ART package가 아래를 소비하도록 함
  - header: `${ARTF_INSTALL_DIR}/include/dtDynamics`
  - library: `${ARTF_INSTALL_DIR}/lib/libdtDynamics.a`
  - CMake package export: `${ARTF_INSTALL_DIR}/lib/cmake/dtDynamics`

- 요구 사항: production 또는 LeoQuad validation에서 기존 isolated prefix `${ARTF_INSTALL_DIR}/dtDynamics` 미요구

## Scope

- 이 release candidate가 고정하는 대상: standalone native `dtDynamics` package
  - Public namespace: `dt::Dynamics`
  - Public CMake target: `dt::Dynamics`
  - Production dependency boundary: `dtMath`만
  - Validation-only reference: MuJoCo 3.8.0, Pinocchio 3.9.0 (private package `.validation_deps/` cache)
  - Package layer: `dtDynSpec`, `dtDynModel`, `dtDynData`
  - 주요 runtime entry point: `ComputeDynamicsRNEA`, `ComputeDynamicsCCRBA`, `ForwardKinematics`, `ComputeJacobians`, point/body/site Jacobian term helper

- native implementation 지원 범위: LeoQuad WBC가 사용하는 현재 MuJoCo-compatible tree model scope
  - world body, fixed body, fixed-base와 floating-base fixture, multi-root fixed/floating fixture
  - body/site transform, mass/bias-force ingredient, Jacobian, `Jdot`, `Jdot*qvel`
  - CoM quantity, centroidal matrix term, 선택적 derivative-style term

## Correct Install Path

- Production install 방식: ART Framework prefix 직접 사용

```bash
cmake --preset release
cmake --build --preset release -- -j2
cmake --install build/release --prefix "${ARTF_INSTALL_DIR:-$HOME/.local/ART_Framework}"
```

- Downstream consumer 권장 resolve 방식:

```cmake
find_package(dtDynamics CONFIG REQUIRED)
target_link_libraries(my_controller PRIVATE dt::Dynamics)
```

- 이 release candidate에서 LeoQuad의 `DTDYNAMICS_INSTALL_PREFIX` 기본값: `${ARTF_INSTALL_DIR}`

## Validation Gate

- rc2 tagging 전 실행:

```bash
tools/audit_release_readiness.sh
```

- LeoQuad installed-package handoff용 (LeoQuad 저장소에서 실행):

```bash
SIMROBOT_PROFILE_DYNAMICS=1 tools/validate_external_dtdynamics_package.sh
```

- LeoQuad gate 필수 보고 항목: `direct_artf_prefix=OK`, `stale_isolated_prefix_pos=-1`, no-GLFW headless trot sequence 통과
